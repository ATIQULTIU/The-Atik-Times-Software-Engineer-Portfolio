## 🗞️ THE FRONT PAGE

**THE ATIK TIMES** is a vintage-inspired developer portfolio designed to present software projects, technical skills, and professional identity through the visual language of a classic newspaper.

Instead of a traditional portfolio layout, this project transforms personal branding into a **digital front page** — combining editorial typography, structured columns, bold headlines, animated elements, and modern responsive design.

**Old-school journalism. Modern technology. One developer.**
